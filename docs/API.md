# Udaan Airlines Sandbox — API Reference

Interactive documentation is generated by FastAPI:

- Swagger UI: <http://localhost:8000/docs> (use **Authorize** to log in)
- ReDoc: <http://localhost:8000/redoc>
- OpenAPI JSON: <http://localhost:8000/openapi.json>

Business rules for each feature are in [features/](features/README.md). The API is a **sandbox**: payments, PNRs and
tickets are simulated.

## Conventions

- Base path: `/api`. JSON in and out, except `POST /api/auth/token`, which takes form data.
- **Authentication:** `Authorization: Bearer <JWT>` from the OAuth2 password grant. Each endpoint lists the scope it
  requires; see [01 · Authentication](features/01-authentication-authorization.md). The booking flow is also open to
  **guests**: payments are secured by `X-Payment-Key` and bookings by the PNR / booking ID plus a passenger's last name.
- Identifiers: `USR001`, `PAX001`, `FLT001`, `FARE001`, `PAY001`, `BK001`, `CHK001`, `TKT001`, `SSR001`, `AC001`, `RT001`.
- PNR: 6 unique characters, never using `0 O 1 I`. It is only disclosed together with a passenger's last name.
- Datetimes are ISO-8601 with an offset, in the **local time of the airport**. A departure sent without an offset is
  read as origin local time. Search dates are local departure dates.

### Errors

Errors always have the shape `{ "detail": "…" }`.

| Status | Meaning |
|---|---|
| 400 | Business-rule violation, bad input or bad credentials |
| 401 | Token missing, invalid or expired (`WWW-Authenticate: Bearer`) |
| 403 | Token lacks a scope, or the resource belongs to another user (for changes) |
| 404 | Not found; this includes other users' records and PNR/last-name mismatches |
| 409 | Conflict: no seats, aircraft busy, already checked in, payment already used |
| 422 | Request schema validation failed |

## End-to-end flow (round trip with connections)

```bash
API=http://localhost:8000/api
TOKEN=$(curl -s -X POST $API/auth/token -d 'username=john&password=password123' | jq -r .access_token)
AUTH="Authorization: Bearer $TOKEN"

# 1. Search: outbound DEL→LHR, return 3 days later (direct + one-stop)
curl "$API/itineraries/search?origin=DEL&destination=LHR&date=2026-09-25&return_date=2026-09-28&adults=1&children=0&infants=0"
#   → outbound[0].flight_ids = ["FLT008","FLT009"], return[0].flight_ids = ["FLT021","FLT025"]

# 2. Passengers (owned by the caller)
curl -X POST $API/passengers -H "$AUTH" -H 'Content-Type: application/json' \
  -d '{"first_name":"John","last_name":"Smith","date_of_birth":"1990-01-01","gender":"M"}'

# 3. Payment (the server prices every passenger on every segment)
curl -X POST $API/payments -H "$AUTH" -H 'Content-Type: application/json' -d '{
  "outbound_flight_ids":["FLT008","FLT009"], "return_flight_ids":["FLT021","FLT025"],
  "class_id":"ECONOMY", "passenger_ids":["PAX001"] }'

# 4. Mock gateway: approve (or REJECT), then complete
curl -X PUT  $API/payments/PAY001 -H "$AUTH" -H 'Content-Type: application/json' -d '{"action":"APPROVE"}'
curl -X POST $API/payments/PAY001/complete -H "$AUTH"

# 5. Booking → PNR
curl -X POST $API/bookings -H "$AUTH" -H 'Content-Type: application/json' -d '{
  "outbound_flight_ids":["FLT008","FLT009"], "return_flight_ids":["FLT021","FLT025"],
  "class_id":"ECONOMY", "passenger_ids":["PAX001"], "payment_id":"PAY001" }'

# 6. Retrieve by PNR + last name
curl "$API/bookings/pnr/65CMD3?last_name=Smith" -H "$AUTH"

# 7. Through check-in for the outbound journey (tickets issued for both segments)
curl -X POST $API/checkins/validate -H "$AUTH" -H 'Content-Type: application/json' -d '{"pnr":"65CMD3","last_name":"Smith"}'
curl -X POST $API/checkins          -H "$AUTH" -H 'Content-Type: application/json' -d '{"pnr":"65CMD3","last_name":"Smith"}'

# 8. Boarding pass
curl "$API/tickets/TKT001" -H "$AUTH"
```

**As a guest:** leave out `-H "$AUTH"`. Keep `access_key` from step 3, send it as `-H "X-Payment-Key: …"` in step 4
and as `"payment_key": "…"` in step 5. Retrieval and check-in only need the PNR and last name.

**Failure path:** `{"action":"REJECT"}` → complete → `FAILED`; `POST /bookings` → `400 "Payment was rejected. The
booking is not confirmed and no seats were reserved."`

## Endpoints

"public" means no token is needed.

### Authentication
| Method | Path | Scope | Description |
|---|---|---|---|
| POST | `/auth/token` | public | OAuth2 password grant (form: `username`, `password`, `scope?`) |
| POST | `/auth/register` | public | Create a customer account (Bronze) |
| GET | `/auth/me` | `profile` | Profile, token scopes, allowed scopes |

### Search, flights and fares
| Method | Path | Scope | Description |
|---|---|---|---|
| GET | `/itineraries/search` | public | `origin`, `destination`, `date`, `return_date?`, `cabin_class?`, `adults`, `children`, `infants` |
| GET | `/flights/search` | public | Direct flights only |
| GET | `/flights` · `/flights/{id}` | public | Flight records, flight with seat availability |
| GET | `/flights/schedules` | `admin` | Paged admin view |
| POST | `/flights/schedules` | `flights:write` | Create a flight (aircraft rotation rule applies) |
| PUT | `/flights/schedules/{id}` | `flights:write` | Retime, re-assign aircraft, renumber, change status |
| GET | `/fares/flight/{id}` | public | Fare and seats per cabin |
| GET | `/fares/ssr/{type}?tier_id=&quantity=` | public | SSR price |
| GET | `/classes` · `/classes/available?flight_id=` | public | Cabins |

### Passengers, payments, bookings
| Method | Path | Scope | Description |
|---|---|---|---|
| GET | `/passengers` · `/passengers/{id}` | `bookings:read` | Own passengers (admin: all) |
| POST | `/passengers` | guest or `passengers:write` | Add a passenger |
| PUT · DELETE | `/passengers/{id}` | `passengers:write` | Manage own passengers |
| POST | `/payments` | guest or `payments:write` | Create a PENDING payment for a trip (returns `access_key`) |
| PUT | `/payments/{id}` | guest (`X-Payment-Key`) or `payments:write` | `APPROVE` / `REJECT` |
| POST | `/payments/{id}/complete` | guest (`X-Payment-Key`) or `payments:write` | APPROVED→COMPLETED, REJECTED→FAILED |
| GET | `/payments/{id}` · `/payments/{id}/status` | guest (`X-Payment-Key`) or `bookings:read` | Payment details |
| GET | `/bookings` | `bookings:read` | Own bookings (admin: all, filters `user_id`, `status`, `pnr`) |
| POST | `/bookings` | guest (`payment_key`) or `bookings:write` | Confirm → PNR |
| GET | `/bookings/pnr/{pnr}?last_name=` | guest or `bookings:read` | **Last name required** |
| GET | `/bookings/{id}?last_name=` | guest or `bookings:read` | Last name required unless you are the owner or an admin |
| PUT | `/bookings/{id}?last_name=` | guest or `bookings:write` | Contact details |
| POST | `/bookings/{id}/change?last_name=` | guest or `bookings:write` | `{direction, new_flight_ids}` |
| POST | `/bookings/{id}/cancel?last_name=` | guest or `bookings:write` | Cancel and refund |
| GET | `/bookings/{id}/history?last_name=` | guest or `bookings:read` | Audit trail |
| DELETE | `/bookings/{id}` | `admin` | Permanently delete a booking and related records |

### Check-in, tickets, SSRs
| Method | Path | Scope | Description |
|---|---|---|---|
| POST | `/checkins/validate` | guest or `checkin:write` | `{pnr, last_name, direction?}` |
| POST | `/checkins` | guest or `checkin:write` | `{pnr, last_name, direction?, passenger_ids?}` → check-ins and boarding passes |
| GET · PUT | `/checkins/{id}` | `bookings:read` / `checkin:write` | Seat change or offload (owner / admin) |
| GET | `/checkins` | `admin` | All check-ins |
| GET | `/tickets/{id}?last_name=` · `/tickets/{id}/boarding-pass` | guest or `bookings:read` | Boarding pass (owner / admin, or a matching last name) |
| GET · POST · DELETE | `/tickets[/{id}]` | `admin` / `tickets:write` | Manual ticketing |
| GET | `/ssrs/catalog` | public | SSR types |
| GET | `/ssrs` · `/ssrs/{id}` · `/ssrs/available` | `ssr:read` | Own SSRs and eligibility |
| POST | `/ssrs` | `ssr:write` + `ssr:<TYPE>` | Create an SSR on a segment |
| DELETE | `/ssrs/{id}` | `ssr:write` | Cancel an SSR |

### Reference and admin
| Method | Path | Scope |
|---|---|---|
| GET | `/airports[/{code}]`, `/routes[/{id}]`, `/routes/valid`, `/routes/sources`, `/routes/destinations?origin=`, `/tiers[/{id}]` | public |
| GET | `/users` | `admin` |
| GET | `/users/{id}` | `profile` (self) / admin |
| GET | `/aircrafts[/{id}]`, `/aircrafts/available?route_id=&departure_time=` | `admin` |
| GET | `/admin/summary` | `admin` |
| GET | `/health` | public |
